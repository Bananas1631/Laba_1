# Глоссарий АС «Репетитор.Просто»

| Термин | Определение |
|---|---|
| Система, АС | Автоматизированная система «Репетитор.Просто» — платформа для организации peer-to-peer репетиторства |
| Peer-to-peer репетиторство (1:1) | Формат индивидуальных занятий, на которых присутствуют только два участника: репетитор и ученик |
| Репетитор | Независимый специалист, оказывающий образовательные услуги, формирующий своё расписание и стоимость занятий |
| Ученик | Получатель образовательных услуг |
| Родитель | Законный представитель несовершеннолетнего ученика, контролирующий качество услуг и расчёты |
| Гость | Незарегистрированный пользователь, который может ознакомиться с платформой и найти репетитора |
| Администратор | Сотрудник, обеспечивающий техподдержку, верификацию пользователей и разрешение спорных ситуаций |
| Анкета (профиль) репетитора | Сведения о репетиторе: образование, опыт, предметы, стоимость, отзывы, рейтинг |
| Верификация | Проверка администратором документов репетитора об образовании и опыте |
| Слот (AvailabilitySlot) | Интервал времени, в который репетитор доступен для занятия |
| Бронирование | Закрепление слота за учеником; на время бронирования слот блокируется для других пользователей |
| Эскроу-оплата | Схема расчётов, при которой оплата замораживается до проведения занятия и затем выплачивается репетитору |
| Возврат | Возврат замороженных средств ученику при отмене занятия |
| Занятие | Урок «один на один» в разделе «Занятия»: видеосвязь, доска, чат |
| Видеосессия | Онлайн-встреча в Яндекс Телемосте, открываемая за 5 минут до начала занятия |
| Домашнее задание (ДЗ) | Задание, выдаваемое репетитором; может проверяться с помощью YandexGPT |
| Отзыв | Текст и числовая оценка ученика после занятия; влияет на рейтинг репетитора |
| Рейтинг | Сводная оценка репетитора по отзывам, используемая при поиске |
| Уведомление | Сообщение Push, SMS или Email о событии системы |
| Личный кабинет | Персональный раздел пользователя, содержимое зависит от роли |
| MVP | Минимально жизнеспособная версия продукта (до 5000 одновременных пользователей) |
| REST API | Интерфейс обмена данными между компонентами по HTTP в формате JSON |
| WebSocket | Протокол двусторонней связи для чата и уведомлений в реальном времени (RFC 6455) |
| CalDAV / iCal | Протокол и формат обмена календарными данными (RFC 4791) |
| ПЭП | Простая электронная подпись (63-ФЗ), которой подтверждаются оферта и акты |
| ОКПД2 85.59 | Код классификатора «Прочие услуги в области образования» |
